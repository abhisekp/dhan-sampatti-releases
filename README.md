# Dhan Sampatti

An Indian property board game for two to four players sharing one device.

[Play on the web](https://dhan-sampatti.app.abhisekp.com) · [Downloads](https://github.com/abhisekp/dhan-sampatti-releases/releases) · [Report a problem](https://github.com/abhisekp/dhan-sampatti-releases/issues)

This public repository holds release downloads and support information. The application source remains private. GitHub's automatically generated source archives contain only this download repository's documents.

## Playing

Name two to four players. Everyone starts at Start with ₹15,000. Roll two dice, buy or pass on an unclaimed property, pay rent to its owner and pay the displayed taxes. Collect ₹2,000 when passing or landing on Start. End each turn and pass the device.

Rent and taxes are capped at the payer's balance. Players with ₹0 remain in play. Fortune, utilities, transit and corner spaces have no extra effect in this release. Construction, trading, bankruptcy, bots, online multiplayer and competitive win conditions are outside this version. All currency is fictional; no real-money wagering is offered.

## Saves and installation

The game saves locally. Use Export save and Import save to move a game between devices or website addresses. Browser storage for the Vercel address and custom domain is separate. Keep an exported copy before replacing a saved game.

Windows downloads are installers for 64-bit Windows. Direct-download installers are currently unsigned; Windows may show a publisher warning. Store publication is a separate process and is pending. Android APK downloads will be added after the signed build and device checks finish. Google Play publication is also pending.

Release candidates are marked pre-release and their notes describe completed checks and remaining verification. Check the SHA-256 checksum against the accompanying file before installing a downloaded binary.
