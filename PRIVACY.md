# Privacy policy

Dhan Sampatti is an offline game for people sharing one device. No account is required. Player names, balances, properties and turn history are saved locally on your device. The native game does not upload game saves and has no ads, purchases or analytics SDK.

Exported JSON files include the player names and game state you entered. You choose where to save or share them. Imports are validated and kept locally. Starting a new game replaces the local save; device settings can erase app data.

The website uses Vercel hosting, which processes ordinary request information to deliver and secure the site. GitHub hosts downloads and support issues under its own privacy policy. Do not post private save files or personal information in public support issues.

Updates and initial downloads need network access. Native Android and Windows game assets are bundled for offline play.

Contact: [support issues](https://github.com/abhisekp/dhan-sampatti-releases/issues).
